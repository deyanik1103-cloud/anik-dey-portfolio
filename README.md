# Anik Dey — Personal Portfolio

A responsive, animated personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Add your portrait
Put your photo at `assets/profile.jpg`. The About section automatically replaces the initials placeholder when this file exists. A square or portrait-oriented image works best.

## Customize
- `index.html`: content, project links, education and contact details.
- `style.css`: color palette, layout, animations and responsive styling.
- `script.js`: scroll reveals, cursor glow, magnetic hover and mobile menu.
